# Лабораторна робота №4 — Практичне 05

Борисенко Нікіта, К-41. PY-C2Q / PR05-C5U.

Відкрийте `report.html` у браузері. Код усієї роботи — `main.py`.

## Запуск

Python 3.12 або новіший; команди з цієї теки:

```sh
python -m pip install -r requirements.txt
python main.py --help
python main.py --dry-run -v
python main.py -v
```

## Результати

- `results/tidy.log` — dry-run і два справжні запуски, нові запуски дописуються.
- `results/run-1.json`, `run-2.json` — знімки початкового доказу; `summary.json` — останній запуск.
- `results/sorted/` — копії за першою літерою; імена збережено.
- `results/thumbnails/` — JPEG 200×200 з водяним знаком.
- `results/photo_clean.jpg` — тестове фото без EXIF.
- `results/files.xlsx` — аркуші «Файли» та «Дублікати», формула AVERAGE в C19.

Повторний запуск пропускає однакові копії та вже створені мініатюри. Якщо вхідне зображення змінилося, для оновлення мініатюр використайте нову `--results`. Імена-конфлікти з іншим вмістом не перезаписуються; програма повідомляє про них і повертає ненульовий код. `--dry-run` записує журнал, але не виконує основних дій. Excel/EXIF-звіт та summary оновлюються при справжньому запуску.

У Excel формули обчислюються після відкриття редактором: openpyxl зберігає їхній текст. HTML-звіт є знімком комплектного прогону; після зміни даних текст і зображення звіту потрібно оновити.
